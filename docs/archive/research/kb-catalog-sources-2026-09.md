# Which sources could get the knowledge base to a thousand games

Date read: 2026-09-17. Read-only research for plan 58 phase 1, lane C. Nothing in this file
changes any code, the search, or which games are in the library today.

## 1. The question

The library covers 25 games today, built one wiki page at a time. Getting anywhere near a
thousand games that way is not realistic — each game needs its own licence check before a single
note can be written, and that check is the slow part, not the writing. The way out is to find
sources that each cover many games under one licence, so a person checks a licence once and it
clears the way for dozens or hundreds of games at once, instead of checking it once per game. This
file looks at the biggest sources of that kind, what each one's licence actually says (never
assumed — read at the source, quoted, dated), and how a page from each could actually be fetched
from this computer: some answer a plain, scripted web request today; some refuse scripted requests
but have a saved copy on the Internet Archive; and at least one refuses both and has only ever been
read by opening it in a browser.

## 4. What one licence check buys

Ranked by how much it unlocks, cheapest first:

1. **The Super Mario Wiki is the biggest single win for the maintainer's own shelf.** One
   licence, already confirmed, covers 11 of their games — 6 already shipped, 5 more planned next
   — and the wiki itself covers the entire Mario franchise, hundreds of games in total, on every
   Nintendo console there has ever been.
2. **StrategyWiki is the biggest win for reaching a thousand games overall.** It is not limited
   to one company's games the way every other source on this list is, so its one licence check
   opens the door to thousands of games at once. The catch is that it cannot be read by a plain
   script today — see § 5.
3. **The Fandom check is fast and repeats well, even though it is not "one" licence.** A quick,
   one-line check per game wiki has already cleared 7 of the maintainer's games (Fallout, GTA,
   Left 4 Dead, Cyberpunk) and today cleared 6 more candidates (Banjo-Kazooie, Banjo-Tooie, Star
   Fox 64, GoldenEye, F-Zero X, Road Rash, ToeJam & Earl) in a few minutes each. It scales to any
   commercially released game that has a Fandom wiki, which is most of them.
4. **wiki.gg works the same way as Fandom** — one quick check per wiki, not one check for the
   whole platform — and covers newer or more niche games that never had a Fandom wiki, such as
   Palworld and Elden Ring.
5. **Wikipedia and UESP round out the list but add less.** Wikipedia's one licence covers almost
   every game that exists, but its writing is too shallow to answer strategy questions. UESP adds
   one franchise (Elder Scrolls) that nobody has written notes for yet.

## 6. Recommendation for the catalog's first hundred games

Start with two sources that are already proven, plus one that is worth the extra setup:

- **The Super Mario Wiki first.** It is already fetching correctly, its licence is settled, and
  it alone can carry the ten-games-and-more this phase is already planning to add.
- **The Fandom check, repeated, second.** The mechanism already exists and already works; running
  it down the rest of the Steam shelf and the emulated shelves a few games at a time is cheap and
  keeps adding games with almost no new work.
- **StrategyWiki third, once its saved copy can be read.** It is the only source here that is not
  limited to one publisher, so it is the one that actually gets the catalog toward a thousand
  games rather than a few hundred. What is unknown: nobody has yet opened that saved copy and
  checked whether its page layout — walkthroughs, tables, per-area pages — comes apart cleanly
  the way the tool that turns a wiki page into notes needs it to. That is worth finding out
  before counting on it.

What else is still unknown: how many wiki.gg wikis exist in total (a directory page showed at
least 20 on one screen and did not show a total); whether the newly found Fandom wikis
(Banjo-Kazooie, Star Fox, GoldenEye, F-Zero, Road Rash, ToeJam & Earl) hold up under the same
close look Zelda and Hades failed; and how much of the "below two hours" and PS2 shelves — the
parts of the maintainer's own library with no shared source at all — are worth the one-off,
per-game checks that the family sources above are specifically meant to avoid.
