The question bubble: what it does now, and four cues

Every bubble below is drawn with the plugin's own values — the same 300 pixel column, the same colours, the same one-line rule. The text is cut by the real rule, not cut by hand, so where a sentence stops is where it would actually stop on the Deck.

Two things are guesses, not measurements. The dark ground behind the column stands in for Steam's own panel, which I have not measured. And the white ring is the plugin's ring — the question bubble switches its own outline off today and is not on the list of things that get that ring, so what it really shows when focused needs one look on the Deck before we pick a cue.

Question 3 and 4 — four cues, each shown with the ring on an earlier, closed turn

Each card shows the same closed turn twice: ring off, then ring on. The cue only ever paints in the second one. Look at the pair, not the single bubble.

The hard three dots are replaced by the text simply fading out at the edge. This is your idea from question 4, turned sideways for a one-line bubble. Quietest of the four.

One thing worth knowing

The question is cut twice today, not once. The code chops it at sixty letters, and then the one-line rule chops it again at whatever fits in the bubble — about forty-eight letters at this size. The second cut almost always wins, so the sixty-letter chop is invisible. Both go away for the open turn; only the one-line rule needs to stay for closed ones.
